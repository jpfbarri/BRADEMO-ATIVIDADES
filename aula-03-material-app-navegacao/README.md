# Aula 3 - Material App e Navegação

Exercícios da disciplina BRADEMO (IFSP).

| Projeto | Exercício |
| --- | --- |
| `exercicio_01_themedata_azul/` | ThemeData com cor de background azul |
| `exercicio_02_themedata_sobrescrito/` | Novo ThemeData sobrescrevendo o inicial com amarelo |
| `exercicio_03_login_navegacao/` | Login (admin / 1234) com navegação e SnackBar de erro |

Cada exercício é um projeto Flutter independente, com o seu próprio
`pubspec.yaml` e `lib/main.dart`.
