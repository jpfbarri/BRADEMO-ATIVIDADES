# Aula 4 - Widgets de Layouts, Inputs, Botões e Diálogos

Exercícios da disciplina BRADEMO (IFSP).

| Projeto | Exercício |
| --- | --- |
| `exercicio_01_gridview/` | GridView com imagens e legenda sobre cada célula |
| `exercicio_02_layout_responsivo/` | Layout responsivo com LayoutBuilder (app de comidas) |
| `exercicio_03_constraints/` | Os 29 exemplos de restrições de layout da documentação |
| `exercicio_04_form_snackbar/` | Form com Column e Row, dados exibidos numa SnackBar |
| `exercicio_05_bottombar_fab/` | FAB encaixado na BottomAppBar, com opções extras |
| `exercicio_06_lista_tarefas/` | Lista de tarefas com Card, Checkbox e AlertDialog |

Cada exercício é um projeto Flutter independente, com o seu próprio
`pubspec.yaml` e `lib/main.dart`.
